# GRE-TUN v12.0.3

مدیریت GRE، GRE Plus، WireGuard و HAProxy.

## اجرای نسخه داخل ZIP

فایل‌ها را استخراج کنید و در پوشه پروژه اجرا کنید:

```bash
sudo bash GRETUN.sh
```

این دستور را روی هر دو سرور اجرا کنید. نیاز به حذف تونل‌های موجود نیست.

## WireGuard روی GRE یا GRE Plus

در منوی ایجاد/ویرایش، WireGuard را انتخاب کنید و نقش سرور و شماره تونل را وارد کنید:

- فقط GRE همان شماره فعال باشد: انتخاب خودکار GRE.
- فقط GRE Plus همان شماره فعال باشد: انتخاب خودکار GRE Plus.
- هر دو فعال باشند: سؤال انتخاب ۱ (GRE) یا ۲ (GRE Plus).
- هیچ‌کدام فعال نباشند: حالت قبلی WireGuard مستقیم از طریق UDP عمومی.
- فعال یعنی اینترفیس موجود و UP؛ تشخیص به پاسخ پینگ وابسته نیست.
- گزینه `00` هنگام انتخاب مسیر بدون توقف WireGuard فعلی به منو برمی‌گردد.

روی هر دو سرور، **شماره تونل و نوع مسیر یکسان** و نقش‌های مکمل ایران/خارج را انتخاب کنید. کلید عمومی هر سرور را در سرور مقابل وارد کنید. اگر پورت خودکار به‌علت اشغال بودن تغییر کرد، پورت Endpoint در تنظیمات سرور مقابل باید برابر ListenPort این سرور باشد.

GRE از آدرس‌های `10.10.N.x` و GRE Plus از `10.30.N.x` برای انتقال استفاده می‌کنند؛ آدرس‌های خود WireGuard همان `10.20.N.x` هستند. مسیر انتخاب‌شده در متادیتا ذخیره می‌شود و برای MTU، فایروال، وابستگی systemd، بررسی سلامت و محافظت در برابر حذف مسیر استفاده می‌شود.

## تغییرات 12.0.3

- پشتیبانی WireGuard از GRE Plus و انتخاب تعاملی وقتی هر دو مسیر فعال‌اند.
- محاسبه MTU از اینترفیس انتخاب‌شده.
- استفاده از آدرس عمومی ذخیره‌شده در مسیر انتخاب‌شده و کنترل سازگاری نقش سرور.
- اضافه‌شدن وابستگی راه‌اندازی WireGuard به سرویس GRE Plus در حالت انتخاب آن.
- جلوگیری از حذف GRE Plus اگر WireGuard هنوز از آن استفاده می‌کند.
- جلوگیری از انتقال تنظیمات اختیاری یک WireGuard به متادیتای قدیمی تونل دیگر.
- حفظ تنظیمات قبلی جلوگیری از ریست ناشی از قطع موقت پینگ.

## بررسی‌ها

```bash
bash -n GRETUN.sh
python3 tests/test_wg_transport.py
```

۱۱ تست خودکار شامل حالت‌های انتخاب مسیر، نقش‌های دو طرف، انصراف، ورودی نامعتبر، MTU، ذخیره تنظیمات، ساخت کانفیگ، قواعد فایروال، وابستگی سرویس و محافظت حذف، با شبکه و سرویس‌های شبیه‌سازی‌شده انجام شده است. اتصال واقعی بین دو سرور در این محیط آزمایش نشده است.
